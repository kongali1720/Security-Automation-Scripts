# Contributing

Thank you for contributing to **Security Automation Scripts**.

---

## Development Standards

Python

- Follow PEP8
- Use type hints
- Maximum line length 88 characters

---

## Bash

Run:

```bash
shellcheck script.sh
```

before submitting Pull Request.

---

## PowerShell

Follow Microsoft's PowerShell Best Practices.

---

## Pull Request Checklist

- Code tested
- No syntax errors
- Documentation updated
- README updated (if needed)
- No secrets committed

---

## Commit Style

```
feat:
fix:
docs:
refactor:
test:
ci:
style:
```

Example

```
feat: add IOC extractor
```
